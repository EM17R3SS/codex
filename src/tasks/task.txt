Задача: реализовать JSON сериализатор.
В JavaScript для сериализации в JSON используется встроенный метод JSON.stringify.
Необходимо самостоятельно реализовать функцию stringify,
которая будет переводить сущности языка JavaScript в JSON строку и возвращать ее.
Оригинальный JSON.stringify принимает три параметра,
в данном задании требуется реализовать поддержку только первого аргумента - непосредственно сериализуемого значения.
